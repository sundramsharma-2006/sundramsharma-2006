## 👋 Hi, I'm Sundram

I'm a second-year **B.Tech CSE (AI & ML)** student at **Graphic Era University, Dehradun**. I build end-to-end data projects: SQL databases, data cleaning and validation, EDA, machine-learning models, dashboards and automated tests.

My habit is simple: **start with a baseline, split by customer or by time, hunt for leakage, and write down what did not work.** If a model fails its target, I say so in the README.

---

## 🧪 Projects (and what they honestly show)

| Project | What I built | Headline result, including the limits |
|---|---|---|
| 🏦 [**Credora Finance**](https://github.com/sundramsharma-2006/credit-risk-loan-analytics) | Credit-risk and loan-approval analytics on a synthetic lending book: 23 data checks, default model, 0-100 risk score, 40 tests | Test ROC-AUC **0.73** (95% CI 0.69-0.77). A random split would have claimed 0.755, so I split by customer. The 0.80 target was **not met**. |
| 🎬 [**Netflix Customer Intelligence & AI Copilot**](https://github.com/sundramsharma-2006/netflix-customer-intelligence-ai-copilot) | Cleaning, 37 SQL queries, churn, segmentation and lifetime-value models, plus an offline copilot with a SQL safety validator and 28 tests | Churn AUC **0.67**, and **0.61** on an out-of-time check. Failed payments are the clearest churn lever (28.4% vs 20.3%). |
| 🍽️ [**Zomato BI & Delivery-Time Prediction**](https://github.com/sundramsharma-2006/zomato-bi-delivery-prediction) | 12-table cleaning pipeline, 26 SQL queries, 38 EDA charts, 23 permutation tests, Power BI build kit | **Neither model beat the baseline** (R² about 0.00, AUC 0.53). The real finding: 33.9% of orders fail and 15.9% of completed orders are late. |
| 🔎 **Semantic search for arXiv papers** *(in progress)* | Cleaned 3.07M arXiv records down to 1.31M papers with DOIs, reproducible 80/20 split, vector search index over the training split | Evaluation against keyword search (BM25) with Recall@k and MRR is being designed. **No results claimed yet.** |

> 📝 Each repo has a README with a status table of what was run, what was only checked, and known data limits.
